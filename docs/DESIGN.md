# AEGIS LANCE 設計メモ

このメモは、コードを読む人・手を入れる人向けに、全体の構成と主な設計判断をまとめたものです。

## 1. 方針

- **ルールは原作に忠実、素材はすべて新規。** 溜め撃ちビーム、着脱式の無敵ポッド、3 色のレーザー、一撃死、地形接触死、
  チェックポイント復帰、コンティニューでスコア下 1 桁に回数が残る、といった「仕組み」は再現しています。
  一方、キャラクター・名称・絵・音楽・効果音・ストーリーは一から作り、既存作品の素材やデータは使っていません。
- **ファイル 1 つで動く。** 画像も音声も外部ファイルを持たず、すべてコードで生成します。ビルドすると約 380KB の HTML 1 枚になります。
- **原作の手触りを保ったまま現代化する。** 論理解像度 384×240（プレイフィールド 384×224）と 60Hz 固定のロジックは当時の基板に合わせ、
  描画・音・UI の側で現代的な表現を足しています。

## 2. 全体構成

```
main.js ── Renderer（gfx/）   シーンバッファ → WebGL ポストエフェクト → 画面
        ├─ Input（core/）      キーボード・ゲームパッド・タッチ・ボットを 1 つの「アクション」に統合
        ├─ AudioEngine（audio/）
        └─ Game（game/game.js） 設定・記録・シーン管理
              └─ シーン（ui/）  タイトル / メニュー / PlayScene / エンディング …
                    └─ World（game/world.js） 1 ステージ分のゲーム本体
```

- **メインループ**（`main.js`）: 60Hz 固定ステップ。`requestAnimationFrame` で経過時間を貯め、1/60 秒ごとに `game.update()`、
  更新があったフレームだけ `game.draw()`。遅いフレームでは最大 5 ステップまで追いつき、それ以上は捨てます。
- **シーン**は `update()` / `draw(r)` / `enter()` / `exit()` を持つ単純なオブジェクトです。遷移は `ui/scenes.js` が Game にぶら下げた関数
  （`goTitle` `startRun` `goEnding` など）に集約し、シーン同士が循環 import しないようにしています。
- **World** の 1 フレーム: タイマー（`after(n, fn)`）→ スクロール → 地形と「動く固体」の更新 → タイムライン（敵の出現・スクロール速度・
  ボス開始）→ 自機 → イージス・ビット → 自弾 → 敵 → 敵弾 → アイテム・ジェム → 衝突判定 → パーティクル → ボスとフェーズの進行。
  ヒットストップ（数フレーム停止）とスロー（1 フレームおきに更新）もここで処理します。

## 3. 描画

### シーンバッファと 2 つの画質

- すべてのゲーム座標は論理ピクセル（384×240）です。シーンバッファはその **S 倍**（画面に合わせた倍率、品質設定で上限あり）で確保し、
  Canvas 2D の変換で論理座標のまま描きます。
- **HD REMASTER**: スプライトはベクター描画の関数として登録されており（`gfx/sprites.js` の `defineSprite`）、現在の S で描いた結果を
  キャッシュします。白フラッシュ用やグロー用のバリエーションも同じ仕組みです。
- **ARCADE 1987**: 同じスプライト関数を 1 倍で描き、`pixelize()` でアルファを 2 値化し RGB を各 4bit に量子化、輪郭線を付けます。
  シーンも 1 倍で描いてから、シェーダーで整数倍に近いシャープなバイリニア拡大をします。
- 切り替えはキャッシュを捨てて作り直すだけなので、プレイ中でも一瞬で切り替わります。

### 手続き生成の素材

- `gfx/art/*.js`: 自機・敵・ボス・エフェクト・ロゴ。グラデーションやパスを重ねる小さな描画キット（`kit.js`）の上に書いています。
- `gfx/textures.js`: 地形テクスチャ（船体パネル、生体細胞、骨、工場の鉄板、心臓組織、岩）。ノイズは `gfx/noise.js` のタイル可能な
  fBm / Voronoi で、1 枚のタイル（128 論理 px）が格子の整数周期ちょうどになるよう倍率を丸めているため、継ぎ目が出ません。
- `game/backgrounds.js`: 多重スクロールの背景（星、星雲、ステーションのリングやトラス、艦隊、洞窟の奥行きなど）。
- `game/terrain.js`: 天井・床の高さフィールド（凹凸ノイズ付き）、破壊できるブロック、動く固体（プレス機・ボスの船体など）。
  ステージ 5 の壁は「蠕動」の波で高さが時間変化します。描画は等高線に沿った暗いバンドで奥行きを出し、縁に照り返しを入れます。

### ポストエフェクト（`gfx/postfx.js`）

1. 輝度抽出 → 1/4 と 1/8 解像度で分離ガウスぼかし（2 段ブルーム）
2. 衝撃波の屈折リング（爆発やビームの発射位置から広がる）、色収差、フラッシュ
3. カラーグレーディング（ステージごとの色味）、ビネット、フィルムグレイン
4. ARCADE 時: 走査線、アパーチャーマスク、画面の湾曲
5. 画面の左右の余白には、ぼかして暗くした映像の続きを描く（黒帯にしない）

WebGL が使えない環境では 2D Canvas に直接拡大描画します（エフェクトなし）。

## 4. 音

- **シンセ**（`audio/synth.js`）: 楽器はすべて Web Audio のノードで組み立てます。
  REMASTERED はデチューンしたノコギリ波の重ね、フィルター付きベース、パッド、合唱風フォルマント、重ねたドラムをリバーブとディレイへ。
  ARCADE FM は 2 オペレーター FM、矩形波アルペジオ、粗い PCM 風ドラムをほぼドライで。どちらも同じ譜面を演奏するので、
  プレイ中に B キーで切り替えても曲は途切れません。
- **譜面**（`audio/mml.js`、`audio/songs/`）: 全 14 曲を MML（音名・長さ・付点・タイ・和音・繰り返し・マクロ）で書いています。
  コード進行からベース・パッド・アルペジオ・ドラムパターンを生成するヘルパー（`songs/gen.js`）もあります。
  単体テストで「全トラックの長さが揃っていること」「ループ位置が正しいこと」を検査しています。
- **シーケンサー**（`audio/audio.js`）: 0.18 秒先までを先読みしてノートを予約する方式。ポーズ中はローパスをかけて音量を下げます。
- **効果音**（`audio/sfx.js`）: すべて合成。同じ音が同時に鳴りすぎないよう最小間隔を設けています。溜め撃ちのチャージ音は連続音で、
  溜まり具合に応じてピッチが上がります。

## 5. ゲームの仕組み

### 当たり判定

敵は `boxes()` で当たり判定の箱（中心と半幅）の配列を返します。箱の種類:

| type | 意味 |
| --- | --- |
| `weak` | 弱点。`mul` 倍のダメージ |
| `body` | 通常の本体。`part` を持つ箱は砲台などの部位で、部位ごとに耐久がある |
| `armor` | 装甲。通常弾は弾かれる |
| `shield` | 完全に無敵（閉じた弱点のふたなど） |

フラグ: `noShot`（自弾は素通り）、`noPod`（イージスは素通り）、`podOnly`（イージスでしかダメージを与えられない）、
`lodge`（射出したイージスがそこに食い込む）。

ダメージの規則（`game/enemy.js` の `damage()`）:

- 通常弾・レーザー: `weak` と `body` にだけ効く。
- ランス（溜め撃ち）: 重なっている箱のうち最も弱い箱（weak > body > armor）に当たる。つまり装甲の後ろの弱点に届く。
  雑魚の軽い装甲は貫いてダメージを与えるが、**ボスと中ボスの装甲には一切効かない**。
- イージス: 雑魚の装甲は削れるが、ボスの装甲は削れない。
- 自弾は地形で止まります。ただし「敵自身が持つ固体」（司令塔の塔体やボスの船体など）は、その敵の露出した `weak` / `body` の箱を
  覆い隠さないようにしています（`World.shotSolid()`）。見えている弱点に撃った弾が手前の判定で消える、ということが起きません。

この規則は、計測によって決めました。以前はランスが装甲にもダメージを与えていたため、ステージ 5・6 のボスは
与ダメージの 9 割以上が「装甲越しのビーム連射」になっていました。原作どおり弱点を狙う戦いにするため、ボスの装甲を完全に無効化し、
代わりに耐久と弱点の露出時間を調整しています（6 章）。

### 自機とイージス

- 自機の弾の当たり判定はコクピット付近の小さな箱、地形との判定は機体全体です。
- 溜め撃ちは 96 フレームで満タン（5 段階）。溜め中も 12 フレームごとに小弾が出ます。
- イージスの状態: `enter`（画面左端から飛来）→ `free` → `front` / `back`（装着）→ `launch`（射出）→ `free` → `recall`（呼び戻し）、
  最終ボスでは `lodged`（核に食い込む）。装着側は、触れたときにイージスが自機より前にいるか後ろにいるかで決まります。
  後方へ射出したイージスは画面端の少し手前で止まるので、回り込んで機首で拾い直せます。
- 装着中のイージスは前方（または後方）に武器を撃ち、クリスタルの色とレベルでレーザーが変わります。

### スコアと残機

- 雑魚・部位・中ボス・ボスに固有の得点。1 発のランスで 2 体目以降を倒すと CHAIN ボーナス
  （チェインの合計が 1,000 → 3,000 → 6,000 → 10,000 → 16,000 … 上限 30,000 になるよう差分を加算。分裂して生まれた破片は数えない）。
- ボス撃破で画面上の敵弾を得点ジェムに変換。
- エクステンドは 50,000 / 150,000 点、以降 150,000 点ごと。
- コンティニューするとスコアの下 1 桁にコンティニュー回数（最大 9）。

### ステージの書き方

`game/stages/util.js` の `timeline()` が、カメラ位置をきっかけに実行されるイベントの列を作ります。

- `at(x, fn)`: カメラが x に来たら実行
- `place(wx, fn)`: ワールド座標 wx の物体を、画面に入る直前に配置
- `scroll(x, v)`: スクロール速度の変更
- `wave(w, kind, n, y, opt)`: 右端から編隊を出す

ボスは `w.startBoss(name, opt)` で開始します（警告 → 曲の切り替え → 登場）。チェックポイントはステージごとの x 座標の配列で、
ミスするとそこまで戻り、イベントは位置に応じて再実行されます。復帰後 2 秒ほどでイージスを運ぶキャリアが飛来します。

### 難易度

`config.js` の `DIFFICULTIES` が、残機、敵弾の速さ、発射間隔、敵の耐久倍率、ミス後のイージス保持、撃ち返し弾の有無を持ちます。
ARCADE が原作どおりの基準です。

## 6. バランス調整の記録

ボットによる計測（ボス直前のチェックポイントから、復帰キャリアのイージス Lv1 と通常弾のみ）:

| ボス | 耐久 | ボス戦の長さ |
| --- | --- | --- |
| IRIS WARDEN | 600 | 約 85 秒 |
| BROODMOTHER | 640 | 約 103 秒 |
| LEVIATHAN CORE | 440 | 約 117 秒 |
| ANVIL | 480 | 約 117 秒 |
| COIL WYRM | 640 | 約 129 秒 |
| BLOOM MOTHER | 1150 | 約 72 秒（イージスの食い込みのみでダメージ） |

ボットは避けることを優先し、レーザーの強化もしていないので、装備の整った人間のプレイではこの半分程度を想定しています。
コイル・ワームは火炎ブレス中に減速して口の判定を広げ、胴体の分泌腺（4 か所）を壊すと大ダメージ、という「狙える隙」を作っています。

## 7. テスト

- **単体テスト**（`npm test`、`node --test`）: MML の解釈、全曲のトラック長とループ、ステージ定義（チェックポイント・曲・イベント）、
  タイムラインが出現させる敵とボスがすべて登録済みであること、ドット絵フォントで描く文字列に欠けた字形がないこと、
  ノイズが整数周期で継ぎ目なくタイルすること、乱数の再現性。
- **E2E**（`npm run e2e`）: Playwright のヘッドレス Chromium で、無敵のボットが全 6 ステージを個別にクリアし、ステージ 1 から
  エンディングまで通しでプレイ（約 12 万フレーム）。全メニュー画面を HD／ARCADE・日英で開き、エラーが出ないことも確認します。
- **同期実行**: `?frames=N` を付けると、描画せずに N フレーム分のロジックを同期実行し、結果を `document.body.dataset.report` に書きます。
  乱数はすべて固定シードなので、同じ URL なら同じ結果になります（`until=clear|boss|ending` で途中終了）。
- **ボット**（`game/bot.js`）: 9 方向の移動候補について、数フレーム先までの敵弾・地形・敵との接触の危険度を見積もり、
  目標（弱点を優先）の高さに合わせながら最も安全な方向を選びます。イージスは機首に付け直し、最終ボスでは開いた核に撃ち込みます。
  タイトル画面のデモプレイにも使っています。

## 8. ビルド

`tools/build.mjs` が esbuild で `src/main.js` を 1 本にまとめ、CSS と同梱フォント（Base64）を埋め込んで `dist/index.html` を出力します。
`dist/artifact.html` は、外側の `<html>` 骨格を付けずに head・body・script だけを並べた埋め込み用の断片です（claude.ai の Artifact 公開用）。GitHub Actions（`.github/workflows/pages.yml`）は、単体テスト・ビルド・E2E が通ったときだけ
`dist/index.html` を GitHub Pages に公開します。

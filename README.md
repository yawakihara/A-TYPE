# VOID LANCE

横スクロールシューティングゲーム。HTML5 Canvas + WebAudio のみで動作し、ブラウザーだけで遊べます（インストール・ビルド不要）。

「溜め撃ちの波動ビーム」「分離できる球体ポッド」「地形のあるスクロール」「チェックポイント復帰」「巨大ボス」といった、
80〜90年代アーケードの横スクロールSTGの作りを土台にした **完全オリジナル作品** です。
グラフィック・BGM・効果音・ステージ・敵・ボスはすべてこのリポジトリ内のコードから生成しており、既存ゲームの素材は一切使っていません。

## 遊び方

| 操作 | キーボード | ゲームパッド | タッチ |
| --- | --- | --- | --- |
| 移動 | 矢印キー / WASD | 左スティック / 十字キー | 左の仮想スティック |
| ショット / 溜め撃ち | Z / Space / J（押しっぱなしでチャージ、離すと発射） | A | FIRE |
| ポッド発射・回収 | X / K | X / B | POD |
| 連射 | C / L（押している間ショットを連射） | Y / LB | - |
| ポーズ | P / Esc / Enter | Start | II |
| ミュート | M | - | - |
| フルスクリーン | F | - | - |
| CRTフィルター | V | - | - |

- ショットは短く押すと通常弾、長押しするとビームがチャージされます（5段階。レベルが上がるほど太く強力になります）。
- **ポッド**はアイテム「O」で入手します。機体前後に装着して弾を防ぎ、接触した敵にダメージを与えます。分離して撃ち込むこともできます。
- ポッドを持っていると、クリスタルアイテムの武器が使えます。
  - **R（ricochet）**: 壁で跳ね返る弾
  - **P（piercer）**: 敵を貫通するレーザー
  - **H（seeker）**: 敵を追尾する弾
- その他のアイテム: `>` 速度アップ / `M` 追尾ミサイル / `T` ビット（周回する僚機、最大2機）
- ミスするとチェックポイントから復帰します（装備は失います）。ボス戦ではボス手前から再開します。
- 難易度（EASY / NORMAL / HARD）、音量、CRTフィルターはタイトル画面で変更できます。サウンドテストもあります。

## ローカルで動かす

ES Modules を使うため、`file://` ではなくHTTPサーバー経由で開きます。

```powershell
node tools/serve.mjs        # http://localhost:8123/
```

Python が入っていれば `python -m http.server 8123` でも構いません（リポジトリ直下で実行）。

## テスト

```powershell
npm test                    # 単体テスト（BGMデータ・地形・ステージ定義・ユーティリティ）
node tools/serve.mjs        # 別ターミナルで起動しておく
.\tools\e2e.ps1             # E2E（Edgeヘッドレス。進行・全アイテム・全武器・ボス撃破・入力・実音声）
.\tools\audiocheck.ps1      # 全BGM/SEをオフライン描画し、音量・クリップ・NaNを検査
```

- 画面の見た目確認用に `tools/sprites.html`（全スプライトの拡大表示）があります。
- URLパラメーターで検証できます: `?stage=2&god=1&bot=1&frames=6000`（ステージ2を無敵のボットで6000フレーム同期実行し、結果をDOMに出力）。

## GitHub Pages で公開する

1. このフォルダーをGitHubリポジトリとして push する（公開リポジトリ）。
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。
3. `main` へ push すると `.github/workflows/pages.yml` が単体テストを実行し、成功すると自動で公開されます。
4. 公開URLは `https://<ユーザー名>.github.io/<リポジトリ名>/` です。

## 構成

```
index.html          エントリーポイント
css/style.css       表示・タッチUI
js/main.js          起動・メインループ(固定60Hz)・整数倍拡大表示・CRTフィルター
js/game.js          状態遷移・衝突判定・HUD・タイトル・コンティニュー・エンディング
js/entities.js      自機・ポッド・ビット・弾・波動ビーム・アイテム
js/enemies.js       通常敵・敵弾・撃破/ダメージ処理
js/bosses.js        ボス3体（ウォーデン / ハイヴ・マザー / ドレッドノート）
js/stages.js        ステージ定義（地形・敵配置・チェックポイント）
js/terrain.js       地形（天井・床）と衝突判定・タイル描画
js/background.js    視差スクロール背景
js/sprites.js       ドット絵の手続き生成（陰影付きSDF・球体・爆発）
js/audio.js         効果音シンセ・BGMシーケンサー
js/music.js         BGM譜面データ（オリジナル曲）
js/input.js         キーボード・ゲームパッド・タッチ入力
js/bot.js           デモプレイ・自動テスト用ボット
tools/              ローカルサーバー・検証ツール
tests/js/           単体テスト
docs/               設計メモ
```

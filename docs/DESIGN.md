# VOID LANCE 設計メモ

## 1. 依頼内容と方針

- 依頼: 往年の横スクロールSTG「R-Type」の完全復刻（キャラクター・効果音・BGMを含め忠実に再現）。GitHub上で外部からも遊べること。
- 判断: 原作のスプライト・BGM・効果音・ステージ構成は権利者の著作物のため、そのままの再現は行わない。
  代わりに **ジャンルの作り（ゲームデザイン）を継承した完全オリジナル作品** として制作した。
  - 継承したもの（アイデア・ルール）: 溜め撃ちビーム、分離できる球体ポッド、地形に当たると即ミス、チェックポイント復帰、アイテムを運ぶ敵、巨大ボス。
  - 新規に作ったもの: 自機・敵・ボスの絵柄、BGM 8曲、効果音、ステージ構成、名称、UI。
- 環境判断: GitHub Pages（静的ホスティング）で十分動くため、HTML5 Canvas + WebAudio のブラウザーゲームとした。素材ファイルを持たず、全てコードから生成する。

## 2. アーキテクチャ

| 層 | ファイル | 役割 |
| --- | --- | --- |
| 起動 | `main.js` | 固定60Hz論理更新、整数倍拡大、CRTフィルター、テスト用同期実行(`?frames=`) |
| ゲーム | `game.js` | 状態: title / soundtest / intro / play / pause / clear / gameover / ending |
| 実体 | `entities.js` `enemies.js` `bosses.js` `fx.js` | 自機・ポッド・ビット・弾・敵・ボス・エフェクト |
| 世界 | `terrain.js` `background.js` `stages.js` | 列(8px)単位の地形、視差背景、イベント列によるステージ進行 |
| 表現 | `sprites.js` `gfx.js` `font.js` `spritedata.js` | SDFによる陰影付きドット絵生成、5x7ビットマップフォント |
| 音 | `audio.js` `music.js` | 合成SE、先読みスケジューラ式BGMシーケンサー、FM/パルス/ベース/パッド等の音色 |
| 入力 | `input.js` | キーボード・ゲームパッド・タッチを統合し、押下/立ち上がり/立ち下がりを提供 |

### 重要な設計判断

- **座標系**: 内部解像度は 384x256（プレイ領域 384x240 + 下部HUD 16px）。画面は整数倍でのみ拡大し、ドットを崩さない。
- **スクロール**: ステージはスクロール位置(px)をキーにしたイベント列。敵は画面座標で動き、地形に張り付く敵(`attached`)のみスクロール量を引く。
- **当たり判定**: 敵は「部位」の配列を返す(`getParts`)。先頭の部位が優先されるため、弱点→破壊可能部位→装甲の順に並べる。装甲は弾を弾く。
- **ボス**: `deferDeath` で撃破演出(連鎖爆発→大爆発)を挟んでからステージクリアへ遷移。コアは「開閉」でダメージが通る時間を制御する。
- **チェックポイント**: ミス時は直近のチェックポイントのスクロール位置へ戻し、イベントポインタを巻き戻す。ボス戦中のミスはボス手前から再開。
- **音**: 全てWebAudioで合成。BGMは `music.js` の文字列譜面（`A4:4`=A4を4ステップ、`+`で和音、`-`で休符）をコンパイルして `audio.js` が先読み予約する。
  `initContext()`/`scheduleSong()`/`sfxAt()` によりオフライン描画でき、音量・クリップの自動検査が可能。
- **再現性**: 乱数はシード付き(`makeRng`)。テスト用ボットは弾・敵・地形を先読みして安全な方向を選ぶ。

## 3. 検証

| 種類 | 手段 | 内容 |
| --- | --- | --- |
| 単体 | `npm test` | BGMの各チャンネル長が曲長と一致、地形の高さ・隙間、ステージ定義の整合、フォント・ユーティリティ |
| E2E | `tools/e2e.ps1` | 起動〜ゲームオーバー/コンティニュー/ポーズ/ステージ遷移/エンディング、全アイテム、全武器、ビーム全レベル、全敵種の更新と描画、3ボスの戦闘と撃破、実キー入力、実AudioEngine |
| 音 | `tools/audiocheck.ps1` | 全BGM/SEをオフライン描画し、ピーク・RMS・クリップ率・NaN・無音率を確認 |
| 目視 | `tools/sprites.html`、ヘッドレスEdgeのスクリーンショット | ドット絵・各ステージ・ボス戦の見た目 |

### 未検証・限界（正直な記載）

- 実機での聴感・操作感（ジャンプ感、弾速、難易度バランス）は未検証。数値検査とボット通しプレイのみ。
- ステージ2・3のボスは、無敵ボットでは撃破まで時間がかかる（弱点が限定的）。人間のプレイでの難易度調整が必要。
- モバイル（タッチ）操作は実機未確認。
- ゲームパッドは実機未確認（Gamepad APIの標準マッピングを想定）。

## 4. 拡張方法

- **ステージ追加**: `stages.js` に `stageN()` を追加し `STAGE_BUILDERS` へ登録。地形は区間配列(`buildTerrain`)、敵配置は `at(スクロール位置, 関数)`。
- **敵追加**: `enemies.js` の `KINDS` に `{hw,hh,hp,score,size,init,update,draw}` を追加。
- **BGM追加**: `music.js` の `SONGS` に追加し、`npm test` でチャンネル長を検証。
